# Туториал эксперта

1. Откройте терминал в `legal-agent-harness`.
2. Запустите: `python scripts/launch_validation_app.py ваш_акт.pdf`.
3. Просмотрите JSON: `records` — ключевые поля, `edges` — направленные связи «акт → изменённая норма». В PDF извлечение best-effort, поэтому обязательно сверяйте результат с официальным документом.
4. Если всё проверено, повторите с `--score 0..10 --comments "..."`. Оценка 0 означает полный провал, 10 — полное соответствие.
5. Для публикации добавьте `--publish --hf-token hf_...`. Токен используется только в памяти текущего запуска и не записывается в журнал.
6. Журнал `validation/reviews.jsonl` содержит только хэш документа, извлечённые поля, граф и оценку. Полный текст и секреты не сохраняются.

Команда с максимальной автоматизацией:

```bash
python scripts/launch_validation_app.py акт.docx --authority "Государственная Дума ФС РФ" --jurisdiction RU --score 8 --comments "Проверена статья и дата" --publish --hf-token hf_ВАШ_ТОКЕН
```

Это учебная проверка качества извлечения, не юридическая консультация. Не загружайте персональные данные и не вставляйте токен в переписку/файлы.
